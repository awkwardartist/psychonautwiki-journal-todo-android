# Overview

The `Category.kt` file is a part of the PsychonautWiki Journal app's Kotlin codebase. It contains a data class representing a category for substances, including its name, description, URL, and color.

# Classes/Types

## Category

This is a data class that represents a category for substances. It has the following properties:

- `name` (String): The name of the category.
- `description` (String): A description of the category.
- `url` (String?): An optional URL associated with the category.
- `color` (Color): The color associated with the category.

# Methods/Functions

There are no methods or functions defined in this file. It is a simple data class used to store information about substance categories.
