# Location.kt

## Overview

The `Location` class is part of a Kotlin codebase designed for managing psychological experiences, specifically focusing on storing location data associated with these experiences. This class is annotated with `@Entity`, indicating that it is intended to be stored in a database using Room persistence library provided by Android Jetpack.

## Classes/Types

### Location

#### Description

The `Location` class represents a location where an experience occurred. It includes properties such as latitude, longitude, and timestamp.

#### Properties

- **latitude (Double)**: The latitude of the location.
- **longitude (Double)**: The longitude of the location.
- **timestamp (Instant)**: The timestamp when the location data was recorded.

## Methods/Functions

This class does not contain any methods or functions at this point. It is designed to be a simple data holder for storing location information associated with an experience, which can be expanded upon as needed in future implementations.
