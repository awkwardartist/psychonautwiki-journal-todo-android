# DoseExplanationScreen.kt

## Overview

The `DoseExplanationScreen` file contains a Composable function that provides detailed instructions on different methods of administering psychoactive substances. This includes information on intranasal administration (snorting), sublingual administration, smoking/drinking, and rectal administration.

---

## Classes/Types

### DoseExplanationScreen

A Composable function that displays information on various methods of substance administration.

#### Parameters
- `modifier`: A Modifier that alters the layout properties of the composable. Default is `Modifier`.

#### Returns
- Unit: The function does not return a value.

---

## Methods/Functions

### Snorting Guide

Provides a brief guide and video on how to properly snort substances without sharing equipment.

#### Parameters
- None

#### Returns
- Unit: The function displays information and opens a YouTube link with the video in a new tab.

### Sublingual Administration Guide

Explains the process of administering substances sublingually, emphasizing safety and proper technique.

#### Parameters
- None

#### Returns
- Unit: The function provides text instructions and guidance on the correct method.

### Smoking/Drinking Guide

Offers advice on safe smoking or drinking practices to minimize risks associated with these methods of administration.

#### Parameters
- None

#### Returns
- Unit: The function displays relevant text information and guidance.

### Rectal Administration Guide

Describes how to administer substances rectally, including safety precautions and the correct technique.

#### Parameters
- None

#### Returns
- Unit: The function provides detailed text instructions and safety advice.
